# Mini Chat

ميني شات "يزيد" من Sity Cloud هو مساعد زجاجي خفيف يوجّه زوار الموقع لأهم الصفحات بالاعتماد على نموذج Gemini.

## تشغيل سريع

1. انسخ ملف الإعدادات ثم ضع مفتاح Gemini الخاص بك:

   ```bash
   cp config.example.js config.js
   ```

   حدّث القيمة `PASTE_YOUR_KEY_HERE` بمفتاحك (المثال المرسل في الرسالة: `AIza...`).

2. شغّل أي خادم ملفات ساكنة (مثال):

   ```bash
   python -m http.server 4173
   ```

3. افتح المتصفح على `http://localhost:4173` وشغّل المساعد.

> **مهم**: المفتاح يُستخدم في المتصفح مباشرة، فالأفضل تحطه على نطاق داخلي أو خلف بروكسي بسيط لو هتطلق المنتج للعامة.

## تخصيص الخبرة

- عدّل محتوى `knowledgeBase` داخل `app.js` ببيانات موقعك الحقيقي (العناوين، الملخّصات، روابط الصفحات، الكلمات المفتاحية).
- غيّر الرسالة الافتتاحية أو الردود الجاهزة في المصفوفة `quickReplies` علشان تناسب صوت البراند.
- تقدر تتحكم في أسلوب الرد من خلال النص الإرشادي داخل الدالة `composePrompt` (عدد الجمل، اللهجة، إلخ).
- خصص الألوان والعناصر الزجاجية من `styles.css` لو احتجت درجات بنفسجي أو أبيض مختلفة.

## كيف بيشتغل؟

1. يجمع نية المستخدم من الرسالة المكتوبة في واجهة الميني شات.
2. يبني برومبت صغير يحتوي على قواعد الرد والـ Knowledge Base.
3. يستدعي Gemini API ويقصّر الرد لجملة أو اتنين.
4. لو حصل خطأ في الاتصال أو المفتاح ناقص، بيقع على fallback محلي يعتمد على الكلمات المفتاحية.

الكود كله JavaScript/HTML/CSS بسيط بدون أي حزم خارجية، فممكن تحطه مباشرة داخل أي صفحة Landing أو داخل Widget جاهز.
