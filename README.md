# GlassViolet WordPress Theme

قالب **GlassViolet** هو قالب ووردبريس متكامل باللغات (HTML/CSS/JS/PHP) يقدم تجربة زجاجية باللون الأبيض والبنفسجي الفاتح، مع دعم كامل للمنتور وخيارات تخصيص مرنة عبر أداة التخصيص (Customizer).

## المميزات الرئيسية
- تصميم زجاجي (Glassmorphism) مع خطوط عربية/لاتينية مدمجة.
- تكامل مع Elementor عبر تسجيل جميع أماكن القالب وتهيئة القوائم والهوكس الأساسية.
- تخصيص مباشر للألوان والنصوص من أداة التخصيص مع تحديث حي.
- نقطة نهاية REST API `glassviolet/v1/hero` لعرض بيانات قسم البطل في تطبيقات خارجية.
- دعم القوائم، الودجات، الشعار المخصص، الصور البارزة، التعليقات، والبلوكات الحديثة.
- حركة Scroll Animations وواجهة قابلة للتعديل من المنتور أو محرر الكتل.

## طريقة الاستخدام
1. انسخ مجلد `glassviolet-theme` إلى المسار `wp-content/themes/` داخل تثبيت ووردبريس.
2. من لوحة التحكم، فعّل قالب **GlassViolet**.
3. استخدم أداة التخصيص لتعديل الألوان والنصوص، أو قم بفتح الصفحات في Elementor لتخصيصها بالكامل.
4. استدعي واجهة REST عبر الرابط `https://your-site.com/wp-json/glassviolet/v1/hero` عند الحاجة.
