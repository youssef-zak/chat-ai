# مركز القيادة الذكي (PHP + Gemini)

منصة دعم عربية متكاملة تجمع بين محادثة النظام والعميل، لوحة تحكم لحظية، وتذاكر دعم فني تُدار بالكامل عبر PHP وواجهة حديثة بـ HTML/CSS/JS. تُستخدم واجهة Gemini Pro للتفاعل مع وكلاء ذكاء اصطناعي لكلٍ منهم مهمة محددة.

## أبرز المزايا
- 🧠 **وكلاء دعم متخصصون**: اختر من ثلاثة وكلاء (مهندس النظام، مدرب النجاح، خبير الدعم) مع تعليمات مختلفة لكل مهمة.
- 💬 **محادثة قوية**: واجهة دردشة تمزج بين رسائل العميل وردود الوكلاء مع حفظ السجل في SQLite أو MySQL.
- 🎫 **تذاكر دعم فني**: افتح تذكرة بالأولوية المناسبة، تُحفظ في قاعدة البيانات مع قائمة بالطلبات الأخيرة.
- 📊 **لوحة معلومات**: إحصائيات عن حجم الرسائل، التذاكر المفتوحة والمنجزة، وآخر نشاط في التذاكر.

## المتطلبات
- PHP 8.1 أو أحدث مع ملحق `curl`، بالإضافة إلى `pdo_sqlite` (للوضع الافتراضي) أو `pdo_mysql` في حال الربط مع خادم MySQL.
- خادم ويب يدعم PHP (Apache/Nginx) أو الخادم المدمج `php -S`.
- مفتاح واجهة Gemini (من [Google AI Studio](https://makersuite.google.com/)).

## خطوات التشغيل
1. **نسخ المشروع** إلى بيئتك المحلية.
2. **اضبط الاتصال بقاعدة البيانات** داخل `backend/config.php`:
   - اترك القيمة `driver => 'sqlite'` لاستخدام الملف المحلي `storage/chat.sqlite` (يُنشأ تلقائيًا).
   - أو غيّر `driver` إلى `mysql` وأدخل بيانات الخادم (`host`, `port`, `dbname`, `username`, `password`).
   - في حالة MySQL، نفّذ ملف `database/schema.sql` مرة واحدة لإنشاء الجداول.
3. **حدّث مفتاح Gemini** في الحقل `gemini_api_key`.
4. (اختياري) عدِّل قائمة الوكلاء داخل المصفوفة `support_agents` لتناسب فريقك.
5. **شغّل الخادم**:
   ```bash
   php -S localhost:8000
   ```
6. افتح المتصفح على `http://localhost:8000` للتفاعل مع لوحة القيادة، الدردشة، وواجهة التذاكر.

> يتم إنشاء قاعدة البيانات تلقائيًا في الوضع الافتراضي (SQLite). لإعادة استخدام قاعدة موجودة أو خادم خارجي، اكتفِ بتعديل إعدادات `backend/config.php` وتشغيل ملف المخطط المناسب (مثلاً `database/schema.sql` لخادم MySQL).

## بنية مهمة الملفات
- `index.php`: واجهة لوحة القيادة، الدردشة، ونماذج التذاكر.
- `assets/styles.css`: تصميم الواجهة المتجاوب.
- `assets/app.js`: منطق الواجهة الأمامية (تحميل الإحصائيات، التذاكر، إرسال الرسائل والتذاكر).
- `backend/config.php`: إعدادات قاعدة البيانات، مفتاح Gemini، ووكلاء الدعم.
- `backend/database.php`: طبقة الوصول لقاعدة البيانات (رسائل وتذاكر، إحصائيات).
- `api/chat.php`: استقبال رسائل العميل وتوجيهها للوكيل المختار وAPI Gemini.
- `api/history.php`: جلب آخر الرسائل مع معلومات الوكلاء.
- `api/agents.php`: إرجاع قائمة الوكلاء للواجهة الأمامية.
- `api/dashboard.php`: إحصائيات فورية للوحة القيادة.
- `api/tickets.php`: إنشاء/عرض التذاكر.
- `database/clear.php`: تفريغ سريع للرسائل والتذاكر أثناء الاختبار.
- `database/schema.sql`: مخطط MySQL (يُنَفَّذ عند استخدام خادم خارجي بدل SQLite).

## تخصيصات سريعة
- يمكن تغيير عدد الرسائل المحفوظة عبر تعديل الوسيط الافتراضي في `Database::getMessages`.
- أضف أو عدّل وكلاء جدد من خلال `support_agents` (كل وكيل يحتوي على `id`, `name`, `emoji`, `mission`, `prompt`).
- يمكن استبدال SQLite بقاعدة أخرى عبر تغيير اتصال PDO في `backend/database.php` وتوفير مخطط مكافئ.
